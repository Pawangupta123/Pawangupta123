### 📦 Featured — I published an npm package

**[`@nexocache/cache`](https://www.npmjs.com/package/@nexocache/cache)** — production-grade caching for Node.js.

<p>
  <a href="https://www.npmjs.com/package/@nexocache/cache"><img src="https://img.shields.io/npm/v/@nexocache/cache?color=cb3837&label=npm"/></a>
  <a href="https://www.npmjs.com/package/@nexocache/cache"><img src="https://img.shields.io/npm/dm/@nexocache/cache?color=cb3837&label=downloads"/></a>
  <img src="https://img.shields.io/badge/dependencies-0-brightgreen"/>
  <img src="https://img.shields.io/badge/tests-557-brightgreen"/>

Most caching libraries solve *how to cache*. This one solves *what happens when the cache breaks* — stampede protection (10,000 concurrent requests → 1 database query), fail-open on Redis failure, distributed locking, tag invalidation, and decorators for both legacy TS and TC39 Stage-3. Zero runtime dependencies, 97% coverage, published with npm provenance from CI.

→ **[github.com/Pawangupta123/CacheForge](https://github.com/Pawangupta123/CacheForge)**
